# PixelCraft AI - SaaS Upgrade Setup Guide

## ✅ Implemented Features

### Backend Features:
1. **Freemium Model** - Free users: 5 images/day, Paid users: unlimited
2. **Credits System** - 1 image = 1 credit, new users get 10 free credits
3. **Payment Integration** - Razorpay integration with 3 plans
4. **Daily Limit Reset** - Auto-reset every 24 hours
5. **Watermark System** - Free users get "Generated by PixelCraft AI" watermark
6. **Security** - Auth middleware, rate limiting, input validation

### Frontend Features:
1. **Payment Modal** - Plan selection and Razorpay checkout
2. **Credits Display** - Show current credits and daily usage
3. **Prompt Gallery** - Predefined prompts (anime, realistic, 3D, etc.)
4. **Login Modal** - Download lock system
5. **AdSense Integration** - Google AdSense component

## 🔧 Environment Variables

Create a `.env` file in the backend folder:

```env
# Server
PORT=5000
NODE_ENV=development

# MongoDB
MONGODB_URI=mongodb://localhost:27017/image-generator

# JWT Secret (generate a random string)
JWT_SECRET=your-super-secret-jwt-key-change-this-in-production

# HuggingFace API (for image generation)
HUGGINGFACE_API_KEY=your-huggingface-api-key
API_TOKEN_URL=https://huggingface.co/api/tasks/text-to-image

# Razorpay Payment Gateway
RAZORPAY_KEY_ID=your-razorpay-key-id
RAZORPAY_KEY_SECRET=your-razorpay-key-secret

# Frontend
REACT_APP_API_URL=http://localhost:5000
REACT_APP_RAZORPAY_KEY_ID=your-razorpay-key-id

# Google AdSense
REACT_APP_ADSENSE_ID=ca-pub-xxxxxxxxxxxxxxxx
REACT_APP_ADSENSE_SLOT=xxxxxxxxxx

# Token/Credit Settings (optional)
DEFAULT_STARTING_CREDITS=10
IMAGE_GENERATION_CREDIT_COST=1
DAILY_FREE_LIMIT=5
```

## 🚀 Setup Steps

### 1. Install Backend Dependencies
```bash
cd backend
npm install razorpay
```

### 2. Configure Razorpay
1. Create account at https://razorpay.com
2. Get API Key ID and Secret from Settings > API Keys
3. Add to `.env` file

### 3. Configure AdSense (Optional)
1. Create Google AdSense account
2. Create ad unit for each slot
3. Get ad client ID and slot IDs
4. Add to `.env` file

### 4. Start Backend
```bash
cd backend
node server.js
```

### 5. Start Frontend
```bash
cd frontend
npm start
```

## 📝 Usage Flow

### Image Generation Flow:
1. User enters prompt
2. Check daily limit (5 for free, unlimited for premium)
3. Deduct 1 credit
4. Generate image
5. Add watermark for free users
6. Return image

### Payment Flow:
1. User selects plan
2. Creates Razorpay order
3. User completes payment
4. Verify payment signature
5. Add credits to user account

### Daily Reset:
- Runs automatically when user generates
- Checks if 24 hours passed since lastReset
- Resets usedToday to 0 for non-premium users

## 🔒 API Endpoints

### Payment & Credits:
| Method | Endpoint | Description |
|--------|----------|------------|
| GET | `/api/payment/plans` | Get available plans |
| POST | `/api/payment/create-order` | Create Razorpay order |
| POST | `/api/payment/verify-payment` | Verify and add credits |
| GET | `/api/payment/subscription-status` | Get user subscription |
| GET | `/api/credits/user-data` | Get user credits data |
| GET | `/api/credits/check-limit` | Check generation limit |
| GET | `/api/credits/balance` | Get credits balance |

## 🎨 Customization

### Change Plans:
Edit `backend/src/controllers/paymentController.js` - `PLANS` object

### Change Watermark Text:
Edit `backend/src/utils/watermark.js` - `WATERMARK_TEXT`

### Change Daily Limit:
Edit `.env` - `DAILY_FREE_LIMIT=5`

### Add More Prompts:
Edit `frontend/src/components/PromptGallery.js` - `PROMPT_CATEGORIES`
